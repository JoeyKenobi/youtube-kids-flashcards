# YouTube Kids Flashcards 🎓

A Chrome extension that makes screen time educational by interrupting YouTube Kids videos with flashcard-style quiz questions.

## Features

- **Automatic flashcard interruptions** — First flashcard appears 15 seconds into each new video, then every 5 minutes
- **Skip detection** — Fast-forwarding more than 30 seconds triggers a flashcard session
- **1,200 questions** across 4 subjects at a 4th-grade level:
  - 📐 Mathematics (300 questions)
  - 📖 Language Arts (300 questions)
  - 🔬 Science (300 questions)
  - 🌍 Social Studies (300 questions)
- **Must answer 5 correctly** before the video resumes
- **Progress tracking** with visual progress bar
- **Works on YouTube Kids** (youtubekids.com)

## How It Works

1. Install the extension
2. Open YouTube Kids and play a video
3. After 15 seconds, a flashcard overlay pauses the video
4. Answer 5 questions correctly to resume watching
5. If the child fast-forwards more than 30 seconds, flashcards trigger again

### For Development
1. Clone this repository
2. Open `chrome://extensions/` in Chrome
3. Enable "Developer mode" (top right)
4. Click "Load unpacked" and select the project folder

## Settings

Access settings through the extension popup:
- **Enable/Disable** the extension
- **Adjust interval** between flashcard sessions (default: 5 minutes)
